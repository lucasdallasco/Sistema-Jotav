# Site Jotav iPhones

Site estático de jotaviphones.com.br, publicado no Netlify.

- `index.html`: o site.
- `dados/*.json`: conteúdo editável (vitrine, manutenção, blindagem, loja, avaliações, perguntas).
- `img/`: imagens do site; `img/produtos/` recebe as fotos enviadas pelo painel.
- `admin/`: Painel da Jotav, em jotaviphones.com.br/admin. Login pelo Netlify Identity; cada publicação vira um commit neste repositório (via Git Gateway) e o Netlify republica o site.

Desenvolvido por Dallas.
